# Farm Foresight: Machine Learning Approach to Sustainable Farming

## Overview
Farm Foresight is a Smart Crop Recommendation System that utilizes advanced machine learning techniques to enhance agricultural productivity, reduce costs, and promote sustainable farming practices by offering farmers data-driven crop recommendations.

## Features
- **Smart Crop Recommendation:** Recommends appropriate crops considering soil health, weather, and historical data.
- **Real-time Data Insights:** Utilizes both real-time and historical agricultural data for optimized decision-making.
- **Precision Farming Tools:** Employs ML algorithms for efficient resource use and lower environmental impact.
- **User-Friendly Interface:** Designed for ease of use with comprehensive support and training provided for farmers.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Database:** SQLite / MySQL (as applicable)

## Methodology
1. **Data Collection:** Compile historical and real-time data regarding weather, soil, and crops.
2. **Data Analysis:** Perform advanced analytics for yield predictions.
3. **Machine Learning Integration:** Use algorithms such as Random Forest, SVM, and Naive Bayes for recommendations.
4. **System Deployment:** Offer actionable insights via a web interface for farmers.

## Installation
```bash
# Clone the repository
git clone https://github.com/Manishk52/Smart-Crop-recommendation.git

# Navigate to the project directory
cd Smart-Crop-recommendation

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```

## Usage
1. Input environmental factors such as soil pH, temperature, humidity, etc.
2. Receive real-time crop recommendations informed by data analysis.
3. Access insights for informed farming decisions.

## Results
- **Increased Crop Yields:** Improvement of 30-35%.
- **Reduced Costs:** Decreased resource wastage and fertilizer consumption.
- **Sustainable Farming:** Adoption of environmentally friendly practices.
